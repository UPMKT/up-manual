# Skill: upscale-ghl-gatilhos

## O que essa skill faz
Catálogo completo de triggers (gatilhos) e actions (ações) do GoHighLevel Workflows. Referência rápida para construção de automações sem precisar abrir a documentação GHL.

## Quando usar
- Ao montar workflows no GHL (via UI ou API)
- Ao revisar automações existentes de um snapshot
- Ao responder "qual trigger usar para X?"
- Ao montar o payload de uma ação via API

## Arquivos

| Arquivo | Conteúdo |
|---------|----------|
| `gatilhos.md` | Todos os triggers GHL com descrição, quando usar, campos configuráveis |
| `acoes.md` | Todas as actions GHL com payload de exemplo e notas |
| `exemplos.md` | Combinações prontas de trigger+action para casos comuns |

## Uso Rápido
"Qual trigger para quando um lead agenda?" → `gatilhos.md` → "Appointment Status Changed" ou "Appointment Created"

"Como mandar mensagem de WhatsApp no workflow?" → `acoes.md` → "Send Message" com channel: WHATSAPP

"Workflow de confirmação de consulta" → `exemplos.md` → "Confirmação D-1"

# upscale-bot-builder

Skill que monta **estrutura completa de bot Conversation AI** no GoHighLevel: bot + pipeline + workflows + calendarios + KB + dashboard.

> **⚠️ GOTCHA CRITICO (aula 02):** `XgMan1AGLtLWMGfcttaJ` eh **share key do link de afiliado**, NAO snapshot ID interno. API V2 aceita esse valor em `snapshotId` sem erro, mas aplica snapshot generico (BUG SILENCIOSO). Sempre use `WffqguAOXJ8oFlkGg2eo` em chamadas API.

## Workflow padrao (5 fases)

| Fase | O que faz | Arquivo |
|------|-----------|---------|
| **1. Reconhecimento** | Inspeciona subconta via 8 chamadas API | `interview/fase-1-reconhecimento.md` |
| **2. Entrevista** | 6 perguntas em pares de 2 | `interview/fase-2-entrevista.md` |
| **3. Arquitetura** | REUSE > ADAPT > CREATE | `interview/fase-3-arquitetura.md` |
| **4a. Geracao via API** | Bot + 6 actions + calendarios (~12min) | `interview/fase-4a-api.md` |
| **4b. UI Manual** | KB + transferBot + Flow Builder (~75min) | `interview/fase-4b-ui-manual.md` |
| **5. Validacao** | Bot Trial 10 cenarios | `interview/fase-5-validacao.md` |

## Convencoes Upscale embutidas

- **Sem em-dash** em qualquer resposta do bot
- **Sem promessa de prazo** sem confirmar agenda
- **Sempre confirmar** dados antes de marcar
- **Tom calmo profissional** (modelo Mariah, validado em prod)
- **Nunca prometer resultado clinico**
- **Discovery antes de criar** (sempre GET o existente antes de POST novo)
